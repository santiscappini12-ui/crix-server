🔑 API de clasificación

  
Usá el cuestionario y las insignias de Crix en tu propio sitio, juego o app. Cada vez que tocás el botón se crea una clave distinta, sin límite de cantidad. Cada una se muestra una sola vez, así que guardala. Si se filtra, borrala y creá otra.

  

  

  

  
Cómo se usa

curl -H "X-Crix-Key: TU_CLAVE" "$ORIGIN/api/v1/rating/config?kind=game&lang=es"

curl -X POST -H "X-Crix-Key: TU_CLAVE" -H "Content-Type: application/json" \
  -d '{"kind":"game","country":"AR","answers":{...},"legal":{...},"declared":true}' \
  $ORIGIN/api/v1/rating/evaluate

<img src="$ORIGIN/api/v1/rating/badge.svg?system=AR&age=12&size=48">

    Límite: 120 pedidos por minuto por clave. Las insignias son propias de Crix, no una clasificación oficial.
